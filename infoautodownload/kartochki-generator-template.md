# Шаблон описаний карточек Gulai Store — спецификация для генератора (CC)

Задача для Claude Code: построить генератор, который по входным данным о товаре
(модель, конфиг, цвет, цена) автоматически собирает готовый текст карточки Авито
в том же стиле, что уже используется в опубликованных карточках Mac и iPhone/iPad.
Ниже — разбор структуры на постоянные и переменные части, плюс примеры по каждой
линейке.

## Общий скелет карточки (одинаковый для всех линеек)

```
[ЗАГОЛОВОК]

[ТЕКСТ ВЕРХА: 1 абзац контекста] (2-4 предложения)

Новый, не активирован, заводская пломба на месте.

[БЛОК ХАРАКТЕРИСТИК: 4-6 строк с emoji]

[ЗАКРЫВАЮЩИЙ БЛОК — один из двух вариантов, см. ниже]
```

## Заголовок — формула

```
{Линейка} {Диагональ/размер?} {Чип} {RAM}/{SSD}[{Цвет}] — новый, оригинал, гарантия 12 мес
```

Примеры из уже опубликованных карточек:
- `MacBook Air 13 M5 16/512GB — новый, оригинал, гарантия 12 мес`
- `MacBook Neo 256GB Indigo — новый, оригинал, чип A18 Pro`
- `iPhone 17 Pro 1TB Синий — новый, оригинал, гарантия 12 мес`
- `iPad Pro 11 M5 256GB Сильвер — новый, оригинал, гарантия 12 мес`

Правила заголовка:
- Пробелы между всеми словами, никогда не слитно (`M5Pro` — неправильно, `M5 Pro` — правильно)
- Формат объёма — `RAM/SSD` слитно через слэш, `GB`/`TB` без пробела перед единицей
  (`16/512GB`, не `16 / 512 GB`)
- Слово «оригинал» — всегда присутствует, это снимает главное возражение
  покупателей на Горбушке (опасение подделки/восстановленного устройства)
- «Гарантия 12 мес» — всегда в заголовке для Mac и iPhone/iPad с гарантией;
  для Neo вместо гарантии в заголовке допустимо «чип A18 Pro» (у линейки другой
  главный аргумент — компактность/новизна чипа, гарантия всё равно есть в
  закрывающем блоке)
- Цвет — только если у линейки принципиально несколько цветов в продаже
  одновременно (Neo, iPhone Pro/Pro Max); если цвет один на весь ассортимент
  линейки — можно не выносить в заголовок

## Текст верха — переменная часть (1 абзац, 2-4 предложения)

Не шаблонная строка "впиши сюда X" — это содержательный абзац, который меняется
по трём осям:

1. **Позиционирование конфига внутри линейки** — базовый вход / апсейл /
   премиум-ниша. Формулировки:
   - Базовый: "вход в линейку без переплаты за то, что нужно не всем"
   - Апсейл по памяти: "если [меньший объём] уже мало для [типовой сценарий],
     а покупать внешний диск не хочется"
   - Премиум/ниша: "для тех, кто [специфичная задача], редкая конфигурация —
     таких на рынке немного"

2. **Что линейка решает для покупателя** (одно предложение, конкретика, не
   маркетинговые общие слова):
   - Air: "тонкий, лёгкий, без вентилятора"
   - Pro: "производительность профессионального уровня"
   - Neo: "самый компактный Mac, который выпускала Apple"
   - iMac: "моноблок «всё в одном» — экран, компьютер и камера в одном корпусе"
   - iPhone Pro/Pro Max: "топовая камера линейки Pro"
   - iPhone база: "всё, что нужно от iPhone, без переплаты за Pro-функции"

3. **Одна конкретная деталь-крючок** (опционально, если есть что сказать):
   редкость конфигурации, конкретный сценарий использования, заметная деталь
   цвета/дизайна.

## Блок характеристик — по линейкам (постоянный набор строк на линейку)

**MacBook (Air/Pro/Neo):**
```
⚙️ Чип Apple {чип}
💾 {RAM} ГБ / {SSD} ГБ SSD   (для Neo — только SSD, без RAM в строке)
🖥️ {диагональ}" {тип экрана}
🔋 До {часы} часов работы от батареи
[доп. строка под линейку — см. ниже]
```
Доп. строка по линейке:
- Air: `⚖️ {вес} кг — самый лёгкий Mac в линейке` (или "мощность без веса Pro" для топовых конфигов)
- Pro: `📷 Face ID, оригинальная клавиатура и трекпад`
- Neo: `🎨 Цвет: {цвет}` + `⚖️ Лёгкий и компактный — удобен для учёбы и работы вне дома`

## Закрывающий блок — ДВА варианта, выбор по типу карточки

**Вариант A — для карточек, где цена в объявлении = цена продажи (Mac):**
```
📦 Гарантия 12 месяцев + проверка устройства перед оплатой — без спешки и лишних вопросов.
📄 Кассовый чек и все документы.
❗ Перед выездом бронируйте устройство.

💰 Цена — при оплате наличными.
💳 Карта / СБП / безнал для юрлиц — +13%.

🚚 Доставка по Москве в день заказа, от 500 ₽. По России — СДЭК, после предоплаты.
📍 Самовывоз: м. Багратионовская, ул. Барклая 8, ТЦ «Горбушкин двор», п/эт., магазин №508 — 5 мин. от метро.

📲 Работаем 24/7 — поможем подобрать вариант под бюджет и задачи.
```

**Вариант B — для карточек в схеме «крючок + реальная цена у бота» (iPhone/iPad,
и любые новые карточки, где явно указано, что используется эта схема):**
```
📦 Гарантия 12 месяцев + проверка устройства перед оплатой — без спешки и лишних вопросов.
📄 Кассовый чек и все документы.
❗ Перед выездом бронируйте устройство.

🚚 Доставка по Москве в день заказа, от 500 ₽. По России — СДЭК, после предоплаты.
📍 Самовывоз: м. Багратионовская, ул. Барклая 8, ТЦ «Горбушкин двор», п/эт., магазин №508 — 5 мин. от метро.

📲 Работаем 24/7 — поможем подобрать вариант под бюджет и задачи.
```
Разница: в варианте B убрана строка «Цена — при оплате наличными» — так как
цена в объявлении там не является финальной ни при каком способе оплаты,
реальную цену всегда озвучивает ИИ-автоответчик.

**Как генератору выбрать вариант:** это управляется отдельным полем на входе
(`pricing_scheme: "direct" | "hook"`), а не автоматически по линейке — обе схемы
могут применяться к любой линейке в будущем, привязки к типу товара нет.

## Что генератор должен принимать на вход (по одной карточке)

```yaml
line: "Air"                    # линейка: Air / Pro14 / Pro16 / Neo / iMac / iPhone / iPhoneProMax / iPadPro / iPadAir
config: "M5 16/512"            # конфигурация
color: "Silver"                # цвет, если применимо
diagonal: "13"                 # диагональ экрана, если применимо
price: 120650                  # цена в карточке (крючок или прямая — по pricing_scheme)
pricing_scheme: "direct"       # direct | hook
tier: "base"                   # base | upsell | premium — влияет на тон абзаца текста верха
```

## Что НЕ должен делать генератор

- Не придумывать новые формулировки закрывающего блока — он фиксированный,
  меняется только целиком по одному из двух вариантов (A/B), без промежуточных
  версий
- Не менять порядок строк в блоке характеристик
- Не добавлять эмодзи сверх набора, использованного в примерах выше — набор
  сознательно ограничен, чтобы карточки выглядели единообразно
- Не генерировать текст верха как случайную вариацию без учёта позиции в
  линейке (tier) — абзац должен явно отражать, база это, апсейл или ниша,
  сокращённый пересказ характеристик без контекста не годится
