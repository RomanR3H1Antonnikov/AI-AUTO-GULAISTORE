# Gulai Store AI Assistant

ИИ-помощница для чатов магазина техники Apple на Авито.  
**Этап 1:** полный функционал через Telegram-бота (Авито API пока не подключён).

---

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Скопировать и заполнить .env
cp .env.example .env
# Заполнить: OPENAI_API_KEY, TELEGRAM_BOT_TOKEN, OWNER_TELEGRAM_ID

# 3. Запустить
python main.py
```

После запуска:
- **Покупатели** пишут боту → получают ответ от помощницы
- **Владелец** (по `OWNER_TELEGRAM_ID`) пишет боту → управляет через команды

---

## Конфигурация

Все параметры — в `config.yaml`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `llm_model` | `gpt-4o` | Модель для генерации ответов |
| `classifier_model` | `gpt-4o-mini` | Модель для определения лидов/токсичности |
| `max_tokens_per_dialog_day` | `10 000` | Токенов в сутки на один диалог |
| `max_tokens_global_day` | `500 000` | Токенов в сутки суммарно |
| `lead_notification_cooldown_minutes` | `30` | Пауза между уведомлениями по одному диалогу |
| `discounts_enabled` | `false` | Включить акции/скидки (когда будут готовы) |

## Где редактировать каталог и базу знаний

**Каталог товаров** → `data/catalog.yaml`  
Структура: категория → список позиций с полями `name`, `config`, `color`, `price`.  
`category_notes` — уточнения, которые попадают в контекст LLM (например, про A18 Pro).

**База знаний магазина** → `data/knowledge_base.yaml`  
Адрес, метро, рейтинг, ключевые факты — всё что знает помощница о магазине.

**Изменения вступают в силу при следующем перезапуске** (YAML читается при старте).

## Команды владельца в Telegram

| Команда | Действие |
|---|---|
| `/stop <chat_id>` | Бот замолкает в этом диалоге (ручной takeover) |
| `/start <chat_id>` | Возобновить бота в диалоге |
| `/status <chat_id>` | Статус диалога, токены, кол-во сообщений |
| `/dialogs` | Список последних 10 диалогов |

`chat_id` = Telegram ID покупателя (цифровой). Бот присылает его в уведомлениях о прогретых лидах.

---

## Уведомления владельцу

Бот присылает уведомления в личку владельца в 4 случаях:

1. **🔔 Прогретый лид** — покупатель назвал время приезда, попросил бронь, спросил реквизиты, сказал «беру»
2. **📌 Эскалация** — вопрос про товар не из каталога ИЛИ попытка торга
3. **⚠️ Токсичное сообщение** — бот замолчал, требуется внимание
4. **⚠️ Лимит токенов** — достигнуто 80% дневного лимита

## Архитектура

```
main.py
└── TelegramAdapter (src/adapters/telegram_adapter.py)
    ├── TelegramTransport  → реализует интерфейс Transport
    └── DialogEngine       (src/core/dialog_engine.py)
        ├── LeadDetector       (LLM + keyword fallback)
        ├── ToxicityDetector   (LLM, консервативный режим)
        ├── StockSource        (заглушка → Google Sheets в фазе 2)
        └── Database           (SQLite WAL, src/storage/database.py)
```

**Ключевой принцип:** `DialogEngine` ничего не знает о Telegram. Весь платформенный код — в адаптере. Переключение на Авито = новый адаптер без изменения логики.

## Подключение Авито (Этап 2)

1. Получить доступ к Avito Messenger API и webhook
2. Реализовать `AvitoTransport` в `src/adapters/avito_adapter.py` (скелет уже есть)
3. **Проверить:** присылает ли вебхук Авито исходящие сообщения продавца?
   - Если **да** → auto-takeover работает автоматически
   - Если **нет** → основной механизм — ручная команда `/stop`, а авто-такeover нужно исследовать
4. **Проверить** актуальные правила Авито: требуется ли пометка «Автоответ» в первом сообщении бота?
5. Заменить `TelegramAdapter` на `AvitoAdapter` в `main.py` (или запустить оба)
